# Moonlight

Family wall calendar for Home Assistant: a shared calendar (with iCloud sync), chores and stars, rewards,
lists, a meal planner and a photo screensaver, made for wall-mounted touchscreens and phones.

- Opens in the Home Assistant sidebar.
- Wall screens open `http://<ha-host>:8091/display` and are paired once, then named and set up in Settings > Screens.
- Data lives in the add-on's `/data`, so it survives updates.

See the Documentation tab for setup.
